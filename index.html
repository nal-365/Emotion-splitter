규격과 사용 팁 자세히 보기
  • 카카오 이모티콘 (멈춤) — 본 이미지 32종 · 360×360 PNG · 150KB 이하 / 아이콘 78×78 PNG · 16KB 이하 / 배경 투명 · 72dpi RGB
  • 네이버 OGQ (멈춤) — 본 이미지 24종 · 740×640 PNG / 메인 240×240 / 탭 96×74
  • LINE 스티커 (정지) — 본 이미지 24·32·40종 · 370×320 이하 PNG / 메인 240×240 / 탭 96×74

프로크리에이트 팁

  • 캔버스를 1440×2880으로 잡으면 4열×8행·칸당 360×360이 딱 맞습니다. OGQ는 4440×2560(6×4), LINE은 2220×1280(6×4)이 기준입니다.
  • 배경을 투명으로 내보냈다면 흰 배경 투명화는 끄고, 흰 배경 JPG·PNG라면 켜세요(오차 8~16부터).
  • 카카오 150KB를 넘는 칸이 있으면 투명화 + 여백 자동 자르기만 켜도 대개 크게 줄어듭니다.
  • 아이콘·메인·탭은 시트의 한 칸을 지정하면 규격 크기(78·240·96×74)로 줄여서 따로 넣어 줍니다.

규격은 바뀔 수 있으니 제안 직전에 각 스토어 공식 가이드를 한 번 더 확인해 주세요. 이 도구는 파일 하나로 동작하고, 이미지는 모두 이 기기 안에서만 처리됩니다.
