# 방구석 작업실 · 이모티콘 분할기

시트 한 장을 카카오 이모티콘 · 네이버 OGQ · LINE 규격 컷으로 한 번에 잘라 주는 **무료 웹툴**입니다.
파일 하나(HTML)로 동작하고, 이미지는 모두 브라우저 안에서만 처리되어 어디로도 전송되지 않습니다.

👉 **바로 쓰기: https://nal-365.github.io/Emotion-splitter/**

## 이런 걸 해 줍니다

1. **시트 넣기** — 완성된 시트 PNG(또는 JPG)를 끌어다 놓습니다.
2. **칸 맞추기** — 파란 격자선으로 잘리는 위치를 확인하고, 여백·테두리를 보정합니다.
3. **내려받기** — 아이콘·메인·탭 컷을 지정한 뒤 ZIP으로 한 번에 저장합니다.

## 지원 규격

| 플랫폼 | 구성 | 컷 크기 | 비고 |
| --- | --- | --- | --- |
| 카카오 이모티콘 (멈춤) | 8×4 = 32종 | 360×360 PNG | 컷당 150KB 이하 · 아이콘 78×78 (16KB 이하) |
| 네이버 OGQ (멈춤) | 6×4 = 24종 | 740×640 PNG | 메인 240×240 · 탭 96×74 |
| LINE 스티커 (정지) | 6×4 · 8×4 · 8×5 | 370×320 PNG | 24·32·40종 · 메인 240×240 · 탭 96×74 |
| 직접 설정 | 원하는 만큼 | 직접 입력 | 열·행·출력 크기 자유 |

## 보정 기능

- **흰 배경 투명화** — 허용 오차(기본 12)를 조절해 흰 배경을 투명하게 (프로크리에이트에서 흰 배경으로 내보낸 경우 유용)
- **여백 자동 자르기(Auto-Trim)** — 칸 안쪽 여백(기본 4%)을 잘라내 크기·용량을 줄임
- **흰 테두리 두께** — 다크모드 대비용 흰 테두리를 원하는 두께로
- **확대 보기 · 체크무늬 배경** — 투명 영역과 잘리는 위치를 눈으로 확인

## 프로크리에이트 팁

- 캔버스는 **1440×2880**으로 잡으면 카카오 32종 시트를 그대로 그릴 수 있습니다.
- 투명 배경으로 내보냈다면 *흰 배경 투명화*는 끄고, 흰 배경 JPG·PNG라면 켜세요(오차 8~16부터).
- 카카오 **150KB**를 넘는 칸이 있으면 투명화 + 여백 자동 자르기만 켜도 대개 크게 줄어듭니다.

## 개인정보

이미지는 서버로 전송되지 않습니다. 모든 처리는 사용자의 브라우저 안에서만 이루어지고, 새로고침하면 사라집니다.
